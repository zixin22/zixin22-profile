# Deploying to GitHub Pages

This site is prepared for the repository `zixin22/zixin22-profile`.

## Recommended GitHub setup

1. Create a new public repository named `zixin22-profile` under the GitHub account `zixin22`.
2. Upload or push the contents of this folder to the repository.
3. In GitHub, open the repository settings and go to Pages.
4. Set the source to deploy from the `main` branch and the root folder.
5. After GitHub Pages finishes building, the site should be available at:

   https://zixin22.github.io/zixin22-profile/

## Notes

- The top navigation currently includes only Home and Publications.
- CV is intentionally not included yet.
- The avatar is intentionally blank until a real profile photo is provided.
- Publications currently point to Google Scholar and can be expanded later after the publication list is verified.
